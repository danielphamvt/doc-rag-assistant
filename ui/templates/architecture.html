System Architecture

Agentic RAG over any document corpus — orchestrated query decomposition, parallel retrieval branches, hybrid search with reranking, and a pluggable model layer. Fully local by default.

Six cooperating layers plus two cross-cutting concerns. Each layer owns one responsibility and exposes a clear contract.

2 · Query Lifecycle

Every question travels this path. Three escalation tiers keep cost proportional to difficulty — the expensive agent loop runs only when decomposition justifies it.

flowchart TD
    IN(["User question"]) --> CLS{"Trivial?
greeting / small talk"}
    CLS -->|yes| DIR["Direct answer
no retrieval, no LLM"]
    CLS -->|no| CXT["Compress context
if history exceeds budget"]

    CXT --> DEC{"Understand query"}
    DEC -->|"ambiguous"| HIL["Ask user for clarification
pause — human-in-the-loop"]
    HIL -->|"user replies"| DEC
    DEC -->|"simple"| ONE["Tier 1
single retrieval pass"]
    DEC -->|"user-forced"| FRC["Tier 2
direct tool invocation"]
    DEC -->|"compound"| AG["Tier 3
agentic loop per sub-question"]

    AG --> LOOP{"Tool needed
and within budget?"}
    LOOP -->|yes| TOOL["Invoke tool
retrieve → rerank → reflect"]
    TOOL --> BUD{"Context size
over threshold?"}
    BUD -->|yes| CMP["Compress working context"]
    CMP --> AG
    BUD -->|no| AG
    LOOP -->|"answered / budget hit"| FALL["Graceful fallback"]

    ONE --> SYN["Synthesis
merge results · attach citations"]
    FRC --> SYN
    FALL --> SYN
    AG --> SYN
    SYN --> OUT(["Cited answer"])

3 · Design Principles

Retrieve small, return largeIndex fine-grained chunks for precision; expand to full parent sections for generation context.
Hybrid searchSemantic recall + lexical precision — identifiers, numbers and exact names need keyword matching.
Rerank after recallOver-fetch candidates cheaply, then reorder with a heavier model — recall and precision decoupled.
Cost-proportional routingTrivial → rules; simple → single pass; compound → agent loop. Pay for agency only when justified.
Ask, don't hallucinateAmbiguity pauses execution for user input instead of forcing a confident wrong answer.
Bounded agencyHard caps on tool calls and iterations; graceful fallback guarantees termination.
Context budgetingContinuous summarization keeps multi-turn loops inside the model window.
TraceabilityEvery generated claim maps back to a retrievable source document.
